# Changelog

Todas as mudanças notáveis neste projeto serão documentadas neste arquivo.

## [1.0.0] - 2025-01-16

### Adicionado
- ✨ Sistema completo de gerenciamento de restaurante
- 🖥️ Interface desktop moderna com C# Windows Forms
- 🌐 Frontend React com TypeScript e design responsivo
- 🔧 Backend Node.js com Express e Prisma ORM
- 📊 Sistema de banco de dados SQLite com suporte a MySQL
- 🚀 Launcher desktop para controle unificado do sistema
- 📁 Estrutura de projeto organizada com documentação
- 🔄 Scripts PowerShell para automação
- 📋 Gerenciamento completo de menu, pedidos e funcionários
- 📈 Sistema de relatórios e analytics

### Organização
- 📂 Criação da pasta `docs/` para documentação
- 📂 Criação da pasta `scripts/` para automação
- 📂 Separação do executável em `RestauranteLauncher-exe/`
- 📄 Documentação detalhada do launcher
- 📄 Guia de configuração MySQL
- 🔧 Arquivo de configuração do projeto

### Técnico
